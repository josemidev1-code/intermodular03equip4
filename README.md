# Intermodular 03 — Equip X

Lloc web educatiu en català sobre quatre sèries de televisió, elaborat amb **HTML5 i CSS3**. Inclou una pàgina principal i quatre pàgines individuals amb imatges, sinopsis, enllaços a IMDb i estils CSS personalitzats.

> **Abans d'entregar:** canvia `equipX` pel número de l'equip, completa els noms i usuaris GitHub dels membres i posa-hi els enllaços reals del repositori i del GitHub Project.

## Tasques i organització

Vegeu [la llista d'issues proposades](docs/tasques.md). Creeu-les al repositori de GitHub i assigneu-ne un responsable a cadascuna. El **GitHub Project** ha de ser públic, amb vista **Board** i estats `To Do`, `In Progress` i `Done`.

- **Repositori públic:** [afegiu-hi l'enllaç]
- **GitHub Project públic:** [afegiu-hi l'enllaç]
- **Flux de treball:** fork del repositori, branca de treball, commits i pull request al repositori original.

## Com executar el web

Obriu `index.html` amb un navegador o utilitzeu l'extensió Live Server de VS Code. No cal instal·lar dependències ni compilar res.

## Disseny i recursos

Les imatges SVG són **il·lustracions originals temàtiques**, no pòsters oficials. Si el professorat exigeix fotografies o pòsters de les sèries, substituïu els fitxers d'`img/` per imatges autoritzades i actualitzeu els noms i atributs `alt` corresponents.

Les sinopsis estan redactades per al projecte; els enllaços dirigeixen a les fitxes de cada sèrie a IMDb.
