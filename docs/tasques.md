## Flux de treball obligatori

1. Cada membre fa **Fork** del repositori original.
2. Clona el fork, crea una branca (`feature/nom-tasca`) i realitza els canvis.
3. Fa commit i push al fork.
4. Obre una **Pull Request** cap a `main` del repositori de l'equip.
5. Una altra persona revisa la PR i, després de validar-la, es fusiona.
6. Es tanca la issue i es mou a **Done**.

## Configuració a GitHub

- **Col·laboradors del repositori:** *Settings → Collaborators → Add people*.
- **Project:** perfil GitHub → *Projects → New project → Board*.
- **Visibilitat:** *Project → Settings → Visibility → Public*.
- **Permisos del Project:** *Project → Settings → Manage access → Invite collaborators → Admin*.

**Important:** els permisos del repositori i del Project són diferents; cal convidar les persones a tots dos llocs.
